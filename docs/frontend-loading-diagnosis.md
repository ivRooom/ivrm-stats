# フロントエンド読み込み診断

トップページとAPIの応答時間が十分短いにもかかわらず、初期表示のまま更新されない場合は、API遅延ではなくブラウザ側のJavaScript実行またはキャッシュを確認する。

## 確認項目

- `index.html`が主要JavaScriptへバージョン付きURLを指定していること
- `page-load-guard.js`が12秒以内に初期表示を終了させること
- 本番スモークテストがHTML内のバージョン付き`app.js`を確認すること
- APIのHTTP応答時間だけで画面初期化成功と判断しないこと

## 想定動作

- 正常時はAPIレスポンスからサービス数と状態を描画する
- JavaScriptが例外停止または古いキャッシュを使用した場合も、12秒後に診断コード付きエラー表示へ切り替える
